# My Personal Notes

The note is basically divided into 

1. **000_+**
	1. to keep the draft version of the notes (Un-categorized  at the time of creation)

2. 001_Meta
	Store the 
	1. **index** 
	2. Template
	3. Media files
	
3. 002_Languages
	Focus: Syntax, standard libraries, and language-specific quirks.
	Use Question as title (Self explanatory or place details if needed) then Short summarized answer and a long answer with syntax and usages

4. 003_Skills
	Focus: Abstract concepts that apply regardless of language, Also connect the concepts with the languages 
	Ex: AI and Python

5. 004_Project
	Focus: On project ideas
	Categorize into 3 sub type - Planned, Ongoing, Done

6. 005_Glance
	 Focus: Cheat-sheet, Links, Papers

7. 006_Organize
	Focus: To do lists
	
8. 007_Temp
	Focus: Temp notes, Regular clean up need on this
