Here is a checklist of the core operations and algorithms for each data structure so you can track your implementation progress.

### 1. Array

* [ ] Searching: Linear Search and Binary Search
* [ ] Basic Sorting: Bubble Sort, Selection Sort, and Insertion Sort
* [ ] Advanced Sorting: Merge Sort and Quick Sort
* [ ] Two Pointers Pattern (e.g., reversing in-place, target sum)
* [ ] Sliding Window Pattern (e.g., max sum of subarray size *k*)
* [ ] Prefix Sum Pattern (e.g., fast range queries)
* [ ] Kadane’s Algorithm (Maximum contiguous subarray)

### 2. Stack

* [ ] Basic Operations: Push, Pop, Peek, and isEmpty
* [ ] Valid Parentheses (Bracket balancing)
* [ ] Expression Evaluation (Postfix / Prefix)
* [ ] Expression Conversion (Infix to Postfix via Shunting Yard)
* [ ] Next Greater Element (Monotonic stack pattern)
* [ ] Min Stack (O(1) time retrieval of the minimum element)

### 3. Queue

* [ ] Basic Operations: Enqueue, Dequeue, Peek, and isEmpty
* [ ] Circular Queue Implementation (Array-based)
* [ ] Priority Queue (Using a Min-Heap or Max-Heap)
* [ ] Deque (Double-Ended Queue) Operations
* [ ] Breadth-First Search (BFS) implementation
* [ ] Sliding Window Maximum (Using a Deque)

### 4. Linked List

* [ ] Singly Linked List: Insertion, Deletion, and Traversal
* [ ] Doubly Linked List: Insertion, Deletion, and Traversal
* [ ] Reverse a Linked List (Iterative approach)
* [ ] Reverse a Linked List (Recursive approach)
* [ ] Detect a Cycle (Floyd’s Tortoise and Hare)
* [ ] Find the Middle Node (Slow and fast pointers)
* [ ] Merge Two Sorted Lists
* [ ] Remove Nth Node from the End
* [ ] Find the Intersection of Two Linked Lists
