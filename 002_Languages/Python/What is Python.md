# What is Python?


> [!Summary] Summary
> - Python is an **interpreted**, **object-oriented, versatile general purpose** programming language 
> - Created by **Guido van Russom** in **1991** with 3 major  versions
> - It is popular due to readability standard library and third libraries
>- It is a multi-paradigm language
>- It is popular in Al, web development, data engineering, automation and testing
>- It lacks performance, native mobile development and also has high memory consumption

- Python is a high-level, interpreted programming language known for its clear syntax and readability. 
- Since its creation by Guido van Rossum in 1991, it has become one of the most popular languages in the world, favored by beginners and experts alike.

## Core Characteristics
- **Readability:** Python uses significant whitespace (indentation) to define code blocks, making it look much more like English than languages like C++ or Java.
- **Interpreted:** You don't need to "compile" Python code before running it. The computer executes the script line-by-line, which makes debugging much faster.
- **Large Standard Library:** Often described as having "batteries included," Python comes with a massive set of built-in tools for everything from handling zip files to managing web servers.
- **Multi-paradigm:** It supports different programming styles, including object-oriented, procedural, and functional programming.
## What is it used for?

Python’s ecosystem is vast, but it dominates in several specific fields:
1. **Data Science & AI:** It is the industry standard for machine learning and data analysis, thanks to libraries like **Pandas**, **NumPy**, and **TensorFlow**.
2. **Web Development:** Frameworks like **Django** and **Flask** allow developers to build the back-end of websites quickly and securely.
3. **Automation/Scripting:** If you have a repetitive task (like renaming 1,000 files or scraping data from a website), a quick Python script can handle it in seconds.
4. **Software Testing:** Many QA engineers use Python to write automated tests for other software applications.

## Pros and cons

|**Pros**|**Cons**|
|---|---|
|**Easy to learn:** Excellent for first-time coders.|**Speed:** It is generally slower than compiled languages like C.|
|**Community:** If you have a problem, someone has already solved it on Stack Overflow.|**Mobile Development:** Not a common choice for native iOS or Android apps.|
|**Versatility:** Works on Windows, macOS, and Linux.|**Memory Consumption:** It can be less efficient with RAM than low-level languages.|
