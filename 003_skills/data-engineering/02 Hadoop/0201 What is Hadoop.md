# What is Hadoop?

> [!Summary] Summary
> - Hadoop is a framework to solve big data problem.
> - It is combination of tools that enables distributed computing
> - It has major 3 components - HDFS, Mapreduce, YARN

- It is framework to solve big data problems.
- It is combination of tools and technologies to solve big data problem.
- There are 3 core components
    1. **HDFS (Hadoop Distributed File System)**: It take care of storage
    2. **MapReduce**: Distributed processing
    3. **YARN(Yet Another Resource Negotiator)**: Resource manager

- Hadoop has three major version
    - Hadoop 1 - 2007
    - Hadoop 2 - 2012
    - Hadoop 3 - Current version

## Why Use It?
- **Scalability:** You can start with a few computers and scale up to thousands just by adding more hardware.
- **Cost-Effectiveness:** It runs on "commodity hardware"—standard, affordable servers—rather than expensive, high-end supercomputers.
- **Flexibility:** Unlike traditional databases that require data to be neatly organized (Structured), Hadoop can store raw data, images, videos, or logs (Unstructured/Semi-structured) and figure out how to read them later.
- **Fault Tolerance:** It assumes hardware will fail eventually and is built to recover automatically without losing work.
