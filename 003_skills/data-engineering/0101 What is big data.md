# What is big data?


> [!Summary] 
> - Its a field of engineering that enables to store and process humongous amount of data which cannot be stored or processed on a single machine in an efficient manner.
> - For this we split the data into small managable chunk. where it can be store and processed across multiple computers.
> - This multiple computer which co-ordinate with each other to store, process data together forms a cluster
> - In big data, the data needs to be following the 5V's. The data should have huge **volume** or the data should flow in with high **velocity** or both The nature of this data can have **variety** of form like structured, unstructured, (Tables, Images, text, Videos) The **value** and **veracity** (quality reliability) of the data is important. As his data is used to make analysis and infer important decisions based on the data.



- **Big data** refers to extremely large and complex datasets that traditional data-processing software simply can’t manage.
- Because big data is too large for a single computer, it is usually handled through **distributed computing**. 
- This involves breaking the data into smaller chunks and processing them simultaneously across a "cluster" of hundreds or thousands of servers.
- To define big data, data scientists typically point to the **"Five Vs"**:

- **Volume:** This refers to the massive scale of data generated and collected. Big Data involves datasets that typically exceed the capacity of traditional databases, ranging from terabytes and petabytes to exabytes and beyond.
- **Variety:** This denotes the diverse types of data encountered, including structured, semi-structured, and unstructured formats. It encompasses text, images, videos, audio, log files, social media posts, and sensor data.
- **Velocity:** This relates to the speed at which data is produced, updated, and processed. Examples include real-time streams from IoT devices, social media, financial transactions, and web traffic, requiring near-real-time processing capabilities.
- **Veracity:** This refers to the quality, reliability, and truthfulness of the data. Because Big Data can be noisy, incomplete, or inconsistent, cleaning and validation processes are necessary to ensure accurate analysis and decision-making.
- **Value:** This represents the ultimate goal of Big Data—the insights and knowledge derived from its analysis. By uncovering patterns, correlations, and trends, organizations can improve efficiency and make better-informed decisions.
