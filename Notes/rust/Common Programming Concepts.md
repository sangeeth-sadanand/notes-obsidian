# Common Programming Concepts

- The foundation of the language relies on [[Notes/rust/Variables and Mutability|Variables and mutability]], where values are immutable by default. 
- You will work with various [[Notes/rust/Data types|Data types]], define logic in [[Notes/rust/Functions|Functions]], and use [[Notes/rust/Comments|Comments]] for documentation. 
- Logic flow is managed through [[Notes/rust/Control Flow|Control Flow]] structures like `if` and `loop`.
